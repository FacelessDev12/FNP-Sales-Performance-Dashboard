# FNP Sales & Revenue Analysis Dashboard

## Project Overview

An interactive Excel dashboard designed to analyze FNP sales and revenue performance. It provides insights into sales trends, products, categories, occasions, cities, and order-time patterns.

## Key Analysis

- Revenue by Occasion
- Revenue by Category
- Monthly Revenue Trends
- Top 5 Products by Revenue
- Top 10 Cities by Orders
- Revenue by Hour
- Average Customer Spending
- Average Order-Delivery Time

## Tools & Skills

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Analysis
- Data Visualization
